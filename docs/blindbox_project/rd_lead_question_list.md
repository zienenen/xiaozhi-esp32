## 1. 使用规则

本文列出研发主管推进一期工程时需要确认的问题。

分类：

| 分类 | 含义 |
| --- | --- |
| 阻塞 | 没确认前不应进入对应实现，否则容易返工或有风险 |
| 非阻塞 | 可以按默认建议推进，后续可调整 |
| 记录 | 已确认或作为后续二期输入 |

如果用户未及时回复，研发主管按“默认建议”推进非阻塞项；阻塞项只推进不依赖该问题的工作。
