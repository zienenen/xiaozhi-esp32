## 3. 产品前提

### 3.1 当前优先级

一期优先完成课题主线：

> 基于小智 ESP32 开源项目，构建景区数据定制化智能体，并通过 GPS 粗定位 + NFC 精准打卡完成指定地点触发交互的 Demo。

市场化主线需要在一期设计中保留扩展口径：

> 面向 18-26 岁潮玩用户，形成 AI 盲盒多性格智能体 + 单一实体机器人 + 出厂绑定角色的商业化产品方向。

### 3.2 三端定义

这里的“三端”是响应式 Web 产品形态，不代表必须开发三套独立系统。

| 端 | 主要对象 | 一期定位 |
| --- | --- | --- |
| PC 管理端 | 原厂管理员、项目管理员、测试人员 | 管理设备、角色、景点、NFC、打卡记录 |
| 平板端 | 展示现场、评审现场、景区演示人员 | 查看演示状态、打卡结果、设备在线状态 |
| 手机端 | 现场调试人员、演示辅助人员 | 快速查看设备状态、打卡结果、必要时执行测试操作 |

### 5.1 统一后台信息架构与样式基线

用户已确认：一期前端需要区分用户端和管理员端。用户端服务盲盒硬件持有者和现场游客，不能做成管理后台；管理员端可以对标小智官网控制台的清爽卡片式体验。

前端原型与设计说明见：[interactive_prototype_design_notes.md](frontend_style_demo/interactive_prototype_design_notes.md)。

| 编号 | 产品要求 | 优先级 | 说明 |
| --- | --- | --- | --- |
| UI-01 | 用户端默认进入对话/伙伴页面 | P0 | 用户只看到当前硬件绑定的专属智能体，不能自己选择或切换智能体 |
| UI-02 | 用户端不出现配置和后台管理入口 | P0 | Prompt、音色、知识库、官网同步、设备绑定都属于管理员端能力 |
| UI-03 | 用户端景区打卡做成游戏化地图 | P0 | 地图点位、硬件定位光圈、GPS/NFC 状态、点位弹窗、印章图鉴 |
| UI-04 | 管理员端左侧保留可隐藏主菜单 | P0 | 承载智能体管理、设备绑定、官网同步等后台能力 |
| UI-05 | 管理员端智能体页采用卡片式工作台 | P0 | 参考小智官网智能体卡片风格，但展示我方业务状态 |
| UI-06 | 管理员端配置采用弹窗 | P0 | 点击配置打开弹窗，不使用右侧区域局部变化作为主要配置入口 |
| UI-07 | 一期前端目标是形式完整、路径清晰、可演示 | P0 | 自研平台应能表现为主要管理平台，同时用户端符合盲盒产品心智 |

### 5.2 用户端“不可切换”的表达修正

用户端“不能自己选择或切换智能体”的产品含义是：当前硬件已经绑定一个专属伙伴，用户只能和这个专属伙伴互动。前端不得把该状态表达为“锁死”“锁定不可用”“未解锁不可用”等容易误解为硬件未连接或功能不可用的状态。

推荐表达：

| 场景 | 推荐文案 | 禁止/不建议文案 |
| --- | --- | --- |
| 当前绑定角色 | 已绑定专属伙伴 | 锁死角色、角色被锁死 |
| 用户不可切换 | 该硬件出厂绑定该伙伴，用户不可自行切换 | 无法使用、未解锁、锁定中 |
| 其他角色展示 | 暂未拥有 / 仅作图鉴展示，不可切换 | 角色异常、设备未连接 |
| 硬件在线且可对话 | 设备在线，正在通过小智官方链路对话 | 锁死、等待解锁 |

如果硬件已经联网并进入小智官方语音链路，用户端应优先展示“在线”“聆听中/思考中/回复中/空闲”“最近真实对话”等状态。不可切换只是一条盲盒绑定规则，不等同于设备、角色或对话链路不可用。

## 6. 核心页面规格

### 6.1 演示总览页

目标：让评审或项目成员一眼看到 Demo 是否跑通。

核心信息：

| 信息 | 说明 | 优先级 |
| --- | --- | --- |
| 当前设备 | 设备名称、SN、在线/离线 | P0 |
| 当前绑定角色 | 角色名称、角色状态、语音配置状态 | P0 |
| 当前 GPS 状态 | 是否有定位、最近定位时间、是否进入点位范围 | P0 |
| 当前 NFC 状态 | 是否识别标签、标签是否有效、对应点位 | P0 |
| 最近打卡结果 | 成功/失败、时间、点位、触发文案 | P0 |
| 景区知识状态 | 数据集名称、启用状态、最后更新时间 | P0 |

关键交互：

| 操作 | 结果 | 优先级 |
| --- | --- | --- |
| 刷新状态 | 重新拉取设备和打卡状态 | P0 |
| 查看设备详情 | 进入设备详情页 | P0 |
| 查看最近记录 | 进入打卡记录页并自动筛选当前设备 | P0 |
| 进入演示大屏模式 | 隐藏复杂操作，只显示演示状态 | P1 |

验收标准：

| 编号 | 标准 |
| --- | --- |
| A-01 | PC、平板、手机均可查看，不出现核心信息遮挡 |
| A-02 | 设备离线、GPS 无信号、NFC 无效、打卡失败均有明确状态 |
| A-03 | 最近一次成功打卡能展示设备、角色、点位和时间 |

## 7. 景区知识与向量库页面说明

用户已确认核心需求 2 优化为：

## 13. 当前结论

一期前端产品范围不应只做一个简单后台。至少需要：

1. 可适配 PC、平板、手机的管理页面；
2. 可展示 GPS 粗定位 + NFC 精准打卡状态的演示页面；
