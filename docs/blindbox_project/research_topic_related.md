## 1. 方向定位

课题方向面向项目申报、技术验证、科研展示或创新性说明，核心表达不是“卖盲盒”，而是“基于三坊七巷多模态文旅数据库的具身智能传播应用研究”。

该方向强调以三坊七巷为单测试景区，以多模态数据库建设为核心主体，以讲解机器人为传播应用载体，完成“标准制定 - 深度建库 - 载体测试 - 效果评估 - 策略输出”的应用研究闭环。

数据库建设应占课题工作量 50% 以上。具身智能机器人不是课题唯一成果，而是验证多模态内容数据库传播效果的落地终端。

## 1.1 选题说明

| 选题依据 | 说明 |
| --- | --- |
| 文旅强省建设现实需求 | 三坊七巷是闽都文化核心载体和我省文旅标志性名片，年接待游客量超千万；当前文旅传播存在内容碎片化、文化深度不足、多模态资源分散等问题，智慧讲解终端内容供给表层化，传播效果与景区地位不匹配 |
| 智慧文旅内容建设行业痛点 | 国内历史文化街区智慧化普遍“重硬件、缺内容”，讲解机器人等终端缺乏标准化多模态内容数据库支撑，导致内容同质化、更新难、复用性差 |
| 闽都文化数字化传播需要 | 三坊七巷承载闽都文化核心价值，传统传播覆盖面有限、形式缺乏新意；通过多模态数据库与具身智能结合，可形成文化内容创意传播的新路径 |
| 应用研究补白价值 | 现有研究多偏技术算法或理论探讨，缺少“数据库建设 - 终端落地 - 效果评估 - 优化策略”全链条应用成果，难以直接指导景区实践 |

## 1.2 研究依据与价值

| 方向 | 现有研究不足 | 本课题价值 |
| --- | --- | --- |
| 历史文化街区文旅传播 | 多聚焦保护开发、文旅融合、短视频和社交媒体传播，缺少具身智能应用传播效能研究 | 从终端互动和传播效果角度补充历史文化街区智慧传播研究 |
| 文旅多模态数据库 | 多为单一模态资源展示库，缺少传播应用导向的内容组织规范和跨模态关联机制 | 建立三坊七巷专属多模态文旅数据库与建库规范 |
| 具身智能应用 | 工程领域重功能实现，社科视角下的内容建设、效果评估和优化策略不足 | 以讲解机器人为载体，验证多模态内容底座对传播效果的提升 |

独到价值：

- 应用价值：建成三坊七巷专属多模态文旅数据库，落地讲解机器人传播原型，输出可落地的传播优化策略，服务三坊七巷智慧服务升级与闽都文化传播。
- 推广价值：形成可复制的“多模态库 + 具身智能”应用传播范式，可推广至我省其他历史文化街区和文旅景区。
- 理论价值：构建历史文化街区多模态文旅数据库建设规范，提炼人工智能赋能文旅传播的优化路径，丰富数字人文与文旅传播交叉研究。

## 5.1 数据库建设指标

以下指标来自课题说明，用于指导课题申报和完整研究成果；一期软件 Demo 可先按最小样例跑通，但文档口径应保留完整建设目标。

| 模态 | 建设内容 | 目标产出 |
| --- | --- | --- |
| 文本 | 建筑详解、名人故事、民俗非遗、历史沿革、实用导览；完成口语化改写、知识点拆分、语义标引、难度分级 | 不少于 2000 条标准化讲解语块、400 组高频问答对，覆盖全街区核心节点 |
| 图像 | 建筑全景、细节特写、历史老照片、名人画像、非遗展示、导览地图；统一尺寸、质量优化、关联知识点 | 不少于 1200 张标准化配图，实现核心知识点“一点一图” |
| 音频 | 标准讲解语音、闽都民俗音效、非遗戏曲片段；统一格式、音量校准、内容关联 | 全街区核心节点讲解音频、50 组场景音效素材 |
| 管理系统 | 资源入库、标引管理、语义检索、跨模态关联、权限管理、内容更新、数据统计、版本管理、标准 API | 支持讲解机器人、小程序等多终端调用 |

| 跨模态关联规则 | 每个核心知识点配套对应图像或音频资源 |
| 讲解场景适配 | 支持定点讲解、动线讲解、主题讲解 |

## 7.1 传播效果评估设计

| 维度 | 指标方向 |
| --- | --- |
| 认知维度 | 文化知识获取、街区认知深度 |
| 情感维度 | 文化认同感、游览满意度 |
| 行为维度 | 推荐意愿、深度游览意愿 |

评估方式：

- 对照实验 A：基于多模态数据库的具身机器人讲解。
- 对照实验 B：传统纯语音导览。
- 量化分析：问卷、评分、任务完成或知识理解测试。
- 质性分析：游客深度访谈、景区管理者访谈。

## 8. 与市场化方向的关系

课题方向关注“技术可行性和创新性”，市场化方向关注“用户价值和商业闭环”。两者共用底层能力，但表达重点不同。

| 共用能力 | 课题表达 |
| --- | --- |
| 盲盒角色硬件 | 多智能体硬件载体 |
| 景点打卡 | 基于位置感知的场景触发 |
| 角色 IP | 差异化智能体人设 |
| 景区知识库 | 垂直领域知识增强 |
| 管理端 | 系统配置与实验观测平台 |
