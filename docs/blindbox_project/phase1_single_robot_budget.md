| 档位 | 金额 | 说明 |

| 推荐预算 | 400-480 元 | 兼顾 PN532、基础备件和焊接耗材。 |

## 5. 选型原则

### 5.1 ESP32-S3

必须选择 ESP32-S3，不建议买普通 ESP32。

原因：

- 小智语音链路对内存和外设要求更高。
- ESP32-S3 对 I2S、PSRAM、语音场景更友好。
- N16R8 的 16MB Flash + 8MB PSRAM 更稳。

### 5.2 NFC

推荐 PN532，不建议为了省几十元换 RC522。

原因：

- PN532 更接近标准 NFC 使用场景。
- 支持 I2C/SPI/UART，调试余地大。
- 后续如果扩展手机 NFC 或更多标签类型，PN532 更安全。

### 5.3 GPS

NEO-6M 和 ATGM336H 都可用，一期重点是 UART NMEA 输出。

注意：

- GPS 室内大概率不稳定。
- 必须准备模拟坐标或测试模式。
- 演示验收应优先在室外或靠窗环境完成。

### 5.4 电源

开发阶段优先 USB 供电，演示阶段再使用电池。

注意：

- 音频播放时电流波动会变大。
- 升压模块质量差可能导致重启。
- 电池供电必须单独做一轮压测。

## 6. 不建议购买

| 项目 | 原因 |
| --- | --- |
| 普通 ESP32 开发板 | 不是目标主控，语音和内存风险高。 |
| 无 PSRAM ESP32-S3 | 后续跑语音和资源容易紧张。 |
| 只充电不传数据的 Type-C 线 | 无法烧录和看串口。 |
| 只有充电没有升压的电池板 | 可能无法稳定给整机供电。 |
| 太小的喇叭 | 声音小，现场演示效果差。 |
| 过于复杂的一体屏幕板 | 一期不做屏幕体验，避免预算和调试复杂度上升。 |

## 7. 收货检查清单

| 项目 | 检查方式 |
| --- | --- |
| ESP32-S3 | 插电脑能识别串口，能烧录基础固件。 |
| 麦克风 | 确认引脚标注清晰：VCC、GND、SCK、WS、SD。 |
| 功放 | 确认 BCLK、LRC、DIN、VIN、GND 标注。 |
| 喇叭 | 接线牢固，无明显破音。 |
| GPS | 上电后指示灯工作，串口有 NMEA 输出。 |
| NFC | 能读取至少一张标签 UID。 |
| 电池 | 电压正常，无鼓包，无破损。 |
| 升压模块 | 输出 5V 稳定，再接主控。 |
| 数据线 | 能烧录，不只是充电。 |
