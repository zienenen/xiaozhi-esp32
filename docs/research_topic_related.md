# 课题相关方向文档

## 1. 方向定位

课题方向面向项目申报、技术验证、科研展示或创新性说明，核心表达不是“卖盲盒”，而是“基于开源智能硬件的多智能体文旅交互系统”。

该方向强调技术路线、系统架构、数据处理、智能体定制、定位触发、人机交互和可验证成果。

## 2. 课题目标

| 目标 | 说明 |
| --- | --- |
| 验证开源硬件智能体改造能力 | 基于小智 ESP32 项目实现定制化语音智能硬件 |
| 验证景区数据驱动智能体 | 使用景区资料构建向量知识库，为智能体提供可靠内容 |
| 验证 GPS 场景触发交互 | 设备到达指定地点后自动触发打卡和讲解 |
| 验证多角色表达差异 | 不同智能体基于同一景区数据呈现不同讲解风格 |
| 验证管理与观测能力 | 通过管理端配置设备、智能体、景点和数据集 |

## 3. 核心技术问题

| 技术问题 | 课题表达 |
| --- | --- |
| 硬件语音交互 | ESP32 端语音采集、播放、状态管理和联网通信 |
| 智能体定制 | 基于角色 prompt、音色配置和景区知识库实现差异化智能体 |
| 景区数据处理 | 原始资料清洗、文本拆分、metadata 标注、向量化入库 |
| 检索增强生成 | 根据用户问题和当前景点上下文检索资料并生成回答 |
| GPS 到点识别 | 基于经纬度、半径和防抖机制实现地点触发 |
| 系统管理 | 通过三端管理页面完成设备、角色、景点、数据集配置 |

## 4. 课题核心功能清单

| 模块 | 功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| 硬件端 | 设备唯一身份 | 设备可被后台识别和管理 | P0 |
| 硬件端 | 语音交互 | 支持唤醒、对话、播报 | P0 |
| 硬件端 | GPS 定位 | 获取当前位置并上报/判断 | P0 |
| 智能体 | 角色配置 | 配置人设、音色、知识库引用 | P0 |
| 数据层 | 景区数据集 | 接入景区资料、FAQ、讲解文本 | P0 |
| 数据层 | 文本拆分 | 按景点、主题、段落拆分 chunk | P0 |
| 数据层 | 向量数据库 | 支持语义检索和 metadata 过滤 | P0 |
| 交互层 | GPS 打卡 | 到指定地点触发打卡 | P0 |
| 交互层 | 景点问答 | 基于当前景点上下文回答问题 | P0 |
| 管理端 | 三端页面 | PC/平板/手机配置和查看状态 | P0 |
| 观测 | 打卡记录 | 查看设备打卡结果和时间 | P1 |

## 5. 一期课题 Demo 范围

| 范围 | 是否一期做 | 说明 |
| --- | --- | --- |
| 小智 ESP32 固件适配 | 是 | 基于现有开源项目二次开发 |
| 设备身份识别 | 是 | 用于绑定和管理 |
| 智能体配置 | 是 | 人设、音色、知识库 |
| 景区数据向量化 | 是 | 课题核心能力之一 |
| GPS 到点打卡 | 是 | 场景触发能力 |
| 角色化讲解 | 是 | 体现多智能体差异 |
| 三端管理页面 | 是 | 配置与演示必需 |
| 复杂商城/用户资产 | 否 | 属于市场化方向 |
| 盲盒商业玩法 | 否 | 课题中可作为应用场景，不作为核心研究内容 |
| 长期记忆成长 | 否 | 后续扩展 |

## 6. 课题系统架构表达

```text
硬件设备层
  ESP32 语音设备 / GPS 模块 / 麦克风 / 扬声器 / 屏幕

通信层
  WebSocket 或 MQTT / 设备身份认证 / 状态上报

智能体服务层
  角色配置 / Prompt 管理 / TTS 音色 / 对话编排

景区知识层
  景区数据集 / 文本拆分 / Metadata / 向量数据库 / RAG 检索

业务应用层
  设备管理 / 角色管理 / 景点管理 / GPS 打卡 / 打卡记录

展示层
  管理端三端页面 / GPS 打卡展示页面
```

## 7. 课题验收指标

| 指标 | 验收方式 |
| --- | --- |
| 设备识别成功 | 后台能识别指定硬件 device_id |
| 智能体加载成功 | 设备能使用绑定角色的人设和音色 |
| 景区数据检索成功 | 用户提问时能召回对应景点资料 |
| GPS 打卡成功 | 进入指定半径后触发打卡 |
| 防重复有效 | 同一景点不会连续重复触发 |
| 三端管理可用 | PC/平板/手机可查看和配置核心数据 |
| 问答内容可解释 | 回答可追溯到景区数据片段 |

## 8. 与市场化方向的关系

课题方向关注“技术可行性和创新性”，市场化方向关注“用户价值和商业闭环”。两者共用底层能力，但表达重点不同。

| 共用能力 | 课题表达 |
| --- | --- |
| 盲盒角色硬件 | 多智能体硬件载体 |
| 景点打卡 | 基于位置感知的场景触发 |
| 角色 IP | 差异化智能体人设 |
| 景区知识库 | 垂直领域知识增强 |
| 管理端 | 系统配置与实验观测平台 |
